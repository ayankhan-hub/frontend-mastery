# 01 — Personal Profile Page

## About the Project

This is my first project in my Frontend Development journey. I created a personal profile page using HTML and CSS to practice the fundamentals of web development.

The page introduces me, my interests, and basic personal information through a simple webpage layout.

## Technologies Used

- HTML5
- CSS3

## Features

- Personal introduction
- Profile information
- Hobbies and interests section
- Basic webpage styling
- Organized HTML structure

## Project Structure

```text
01-personal-profile-page/
├── index.html
├── style.css
└── README.md
```

## How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/ayankhan-hub/frontend-mastery.git
   ```

2. Open the `01-personal-profile-page` folder.
3. Open `index.html` in your browser.
